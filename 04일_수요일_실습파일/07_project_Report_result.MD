이 파일은 07번 실습 결과에 관한 보고 자료입니다.


이미지뿐만 아니라 동영상(프레임 배열)까지 확장하여 흑백 변환, 크기 조절, 에지(Edge) 검출을 연속으로 처리하는 종합 실습입니다.



1. 실험 시작

실습을 시작하기에 앞서 기본으로 주어진 코드에 해당하는 값을 지급하여 정답 과정과 실패 과정, 정답과 오답의 결과를 모두 확인하였습니다.

처음 보유한 이미지를 회색으로 변경하고, 그 후에 이미지의 사이즈를 너비를 160, 높이를 120으로 축소하는 작업을 진행 하였습니다.
정답이 아닌 다른 값 출력을 위해 이미지 슬라이싱 코드를 사용해 각각 160, 120으로 맞춰보았고 그 결과물은 사이즈에 맞게 줄이는게 아닌 160과 120에 해당하는 부분을 오려내는 crop 방식으로 오답을 확인습하였습니다.
-> resize로 크기를 줄여야 정확하게 오리는게 아닌 축소를 합니다. 그러면서 이미지를 축소할 때 픽셀이 뭉개지거나 깨지는 계단 현상을 방지하고 화질을 가장 부드럽고 깨끗하게 유지해 주는 명령어로 interpolation=cv2.INTER_AREA를 입력 했습니다.


주어진 small 함수에 canny 를 적용하여 edge를 검출하는 과정을 진행 하였습니다. 주어진 임계값 80과 160으로 edge를 검출 하였습니다.
정답이 아닌 다른 값 출력을 위해 임계값을 높여 보았습니다.(150, 250)
-> 기준이 너무 깐깐해져서 조금만 흐릿한 선도 다 지워버립니다. 굵직하고 명확한 외곽선만 조금 남고 에지가 뚝뚝 끊기거나 사라집니다.
•임계값을 낮추면? (20, 50)
-> 기준이 너무 너그러워져서 자잘한 노이즈나 사물의 미세한 질감, 그림자 경계선까지 전부 에지로 인식합니다. 화면 전체가 지저분한 그물망처럼 선으로 가득 차게 됩니다.


동영상 저장을 위해 출력 객체를 생성했습니다.
위에 주어진 조건 (160과 120 사이즈, 프레임 수)에 맞춰 동영상을 생성하기 위해 원본 비디오의 초당 프레임 수를 그대로 복사해 왔습니다.
주어진 기본 값이 공란 없이 제대로 설정 되어 있어서 값 변경 하지 않고 그대로 진행 할 수 있었습니다.
문제는 프레임 값에 주어져야 할 값이 제대로 입력되지 않고 공란으로 있어 이미지 (동영상) 생성 과정이 진행되지 않아 직접 값을 입력해야한다라는 사실을 알게 되었고, 공란 3줄 중 맨 윗 줄의 회색 프레임 값에 cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY) 명령어를 사용하여 정확히 흑백으로 바꿔주었습니다.
다음은 사이즈 프레임에 규격을 입력하여(160, 120)의 사이즈와 interpolation=cv2.INTER_AREA 이미지의 선명도를 올리는 작업을 하였습니다.
마지막으로 canny 함수를 이용해 사이즈를 줄이고, edge 검수 까지 완료 하였습니다.
이 과정을 거쳐서 이미지 생성까지 무사히 완료 하는걸 확인 하였습니다.
